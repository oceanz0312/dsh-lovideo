# lovideo 视频

在 DeepSeek Harness 里一句话做出任意风格的视频。

- **你自己提供**：模型（DeepSeek Harness 里选的那个）、算力（这台电脑的 CPU 和显卡）、配音配乐的 key（可以不填，默认用系统自带语音）。
- **插件提供**：导演和制作流程、平台风格库（登录 lovideo 即可免费使用）、作品管理、蒸馏自己的风格、导出 MP4 和剪映工程。

## 怎么用

1. 新建会话时选「lovideo 导演」，或在任何会话里说「帮我做个视频」。
2. 导演会推荐风格、出分镜；点卡片上的「确认开拍」，片子在你的电脑上制作，进度实时显示。
3. 做好后在卡片里播放；想改直接说（裁短、换顺序、改字幕、重画某一镜）。
4. 导出 MP4 或剪映工程。

侧栏的「lovideo 视频」里可以随时查看作品、平台风格和我的风格，修改设置。

## 限制

- 首次制作前要准备渲染环境（浏览器、ffmpeg），电脑上没有的会下载，约 150 MB。
- 需要独立显卡的 3D 风格在集成显卡上会很慢。
- 剪映工程导出需要 Python 3（macOS 自带）。
