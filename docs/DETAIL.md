# lovideo 视频

在 DeepSeek Harness 里一句话做出任意风格的视频。

- **你自己提供**：模型（DeepSeek Harness 里选的那个）、算力（这台电脑的 CPU 和显卡）。配音、配乐默认在这台电脑上离线生成（一键下载），也可以填自己的配音、配乐服务 key。
- **插件提供**：导演和制作流程、平台风格库（登录 lovideo 即可免费使用）、作品管理、蒸馏自己的风格、导出 MP4 和剪映工程。

## 安装

在 DeepSeek Harness「插件 → 添加插件」里填 `dsh-lovideo`。国内网络也能装（会自动换国内的 npm 镜像）；填 GitHub 地址在国内可能装不上。

## 怎么用

1. 新建会话时选「lovideo 导演」，或在任何会话里说「帮我做个视频」。
2. 导演会推荐风格、出分镜，并建议要不要配音、配乐和字幕；分镜卡上可以改时长（30 秒到 5 分钟）和这几个开关。点「确认开拍」，片子在你的电脑上制作，进度实时显示。
3. 做好后在卡片里播放，播放器下面可以随时开关配音、字幕、配乐；想改直接说（裁短、换顺序、改字幕、重画某一镜）。
4. 导出 MP4 或剪映工程。

侧栏的「lovideo 视频」里可以随时查看作品、平台风格和我的风格，修改设置。

## 限制

- 首次制作前要准备渲染环境（浏览器、ffmpeg），电脑上没有的会下载，约 150 MB；国内网络会自动走国内镜像。实在下不动时，自己装好 Chrome / Edge 或 ffmpeg 再点一次「准备」也行。
- 3D 绘制的风格渲染得慢一些。
- 剪映工程导出需要 Python 3（macOS 自带）。
