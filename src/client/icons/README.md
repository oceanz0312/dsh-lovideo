# 发布平台的标志

画幅浮层里「适合」那一行用的平台标志。全部是开源图标库的原文件，内容没有改；界面把它当形状蒙版，
盖在平台品牌色的小方块上显示成白色（见 `../platforms.js`）。和 lovideo.ai 网站用的是同一套文件。

| 文件 | 来源 | 许可 |
| --- | --- | --- |
| `youtube.svg`、`youtube-shorts.svg`、`bilibili.svg`、`tiktok.svg`、`kuaishou.svg`、`xiaohongshu.svg`、`instagram.svg` | Simple Icons | CC0 1.0 |
| `wechat-channels.svg` | Remix Icon | Apache 2.0 |
| `xigua.svg` | IconPark | Apache 2.0 |

抖音没有开源图标，和 TikTok 是同一个标志，用 `tiktok.svg`；Reels 没有单独的图标，用 `instagram.svg`。
